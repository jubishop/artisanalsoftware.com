# Domain management

`artisanalsoftware.com` transferred from Squarespace to Cloudflare in March
2026. Cloudflare is the recorded registrar and DNS provider. The former memory
index still named Squarespace; that index was stale.

Check the Cloudflare account and Railway domain settings before changing DNS.
Use [the deployment runbook](../docs/deployment.md) for service context and the
source of current DNS targets. This migration did not reverify either account.
